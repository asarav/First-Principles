# Roadmap

## Milestone 0 — Foundation (current)

Godot 4 project, deterministic combinational simulation, data-driven puzzles, validator, save/load, headless tests, functional workbench, tiny campaign loop.

## Milestone 1 — Workbench depth

Smoother placement/connection, clearer port state, pause vs settle, better failure explanations, construction history.

## Milestone 2 — Campaign shell

Richer timeline presentation, cryosleep as an explicit player action, era changes that are visible in the hub.

## Milestone 3 — Second computational vocabulary

Add a non-boolean or non-circuit puzzle family without forking the simulation engine.

## Later

Human-authored landmark puzzles, discoveries, and the familiar → strange → understood progression from `MASTER_SPEC.md`.
